# From Zero Setup

Setup base para futuras instalaciones.

# Ejecucion

Se necesita un usuario no root, pero que tenga permisos de superusuario `sudo`. Hay 2 opciones, segun que venga instalado:

```bash
curl -fsSL https://raw.githubusercontent.com/FORGIS98/from-zero-setup/main/bootstrap.sh | bash
wget -qO- https://raw.githubusercontent.com/FORGIS98/from-zero-setup/main/bootstrap.sh | bash
```

Esta probado en [EndeavourOS](https://endeavouros.com/).
